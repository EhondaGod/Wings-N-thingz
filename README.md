# Wings n Thingz — Responsive Restaurant Landing Page

A modern, responsive landing page designed for **Wings n Thingz**, a local restaurant. This project focuses on clean code structure, strong visual hierarchy, and cross-device adaptability using pure HTML and CSS.

## Key Features
* **Fully Responsive Design:** Built with custom CSS media queries to ensure smooth layout transitions across mobile phones, tablets, and desktop monitors.
* **Semantic HTML5:** Structured with accessible, meaningful tags for better SEO and screen-reader compatibility.
* **Zero-Framework Styling:** Crafted entirely with vanilla CSS, demonstrating core layout, spacing, and responsive styling fundamentals.
* **Local Business Focus:** Designed to highlight menu items, location details, and clear calls-to-action for hungry visitors.

## Technologies Used
* **HTML5**
* **CSS3** (Custom Media Queries, Flexbox/Grid)
